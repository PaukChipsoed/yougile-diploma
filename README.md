# YouGile — дипломный проект по автоматизации тестирования

Дипломный проект по автоматизации тестирования веб-приложения **YouGile**.

Проект содержит автоматизированные **UI- и API-тесты** на Python с использованием pytest, Selenium, Requests и Allure.

## Технологии

* Python
* pytest
* Selenium
* Requests
* python-dotenv
* Allure
* Git / GitHub

## Установка

Клонировать проект и перейти в его директорию.

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Переменные окружения

Для работы проекта используется файл `.env`.

В нём должны быть указаны:

```text
YOUGILE_EMAIL=...
YOUGILE_PASSWORD=...
YOUGILE_TOKEN=...
YOUGILE_COLUMN_ID=...
```

Файл `.env` не добавляется в Git-репозиторий, так как содержит конфиденциальные данные.

## Запуск тестов

Запустить все тесты:

```bash
pytest -v
```

Запустить только UI-тесты:

```bash
pytest -m ui -v
```

Запустить только API-тесты:

```bash
pytest -m api -v
```

## API-тесты

В проекте реализованы проверки:

1. Создание задачи через API — проверка ответа `201`.
2. Создание задачи с пустым названием — проверка ответа `400` и тела ошибки.
3. Получение существующей задачи — проверка ответа `200` и данных задачи.
4. Получение несуществующей задачи — проверка ответа `404` и тела ошибки.
5. Обновление задачи — проверка изменения задачи через API.

## UI-тесты

В проекте реализованы проверки:

1. Открытие главной страницы YouGile.
2. Создание задачи.
3. Открытие карточки задачи.
4. Редактирование названия задачи.
5. Удаление задачи.
6. Завершение задачи.

Для UI-тестов используется Selenium и явные ожидания `WebDriverWait`.

В тестах не используется `time.sleep()`.

## Allure

Для формирования результатов Allure:

```bash
pytest --alluredir=allure-results
```

Для открытия отчёта:

```bash
allure serve allure-results
```

## Особенности проекта

* UI-тесты используют Page Object.
* API-тесты выполняются с использованием Requests.
* Для авторизации и конфигурации используются переменные окружения.
* Тесты разделены на UI и API с помощью pytest-маркеров.
* Для тестов добавлены Allure-описания и шаги.
* Секретные данные не хранятся в репозитории.
* В проекте используются явные ожидания Selenium.
* Код оформлен с учётом требований PEP 8.
